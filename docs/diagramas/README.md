## 🎨 Tipos de diagramas

| Tipo | Uso |
|---|---|
| **Flowchart** | Flujos de proceso |
| **Sequence** | Interacción entre componentes |
| **State** | Máquinas de estado |
| **ER** | Modelo de datos |
| **Class** | Estructura de clases |
| **Gantt** | Roadmap y planificación |
| **Pie** | Distribuciones |
| **Mindmap** | Mapa conceptual |
| **Timeline** | Evolución histórica |
| **Sankey** | Flujos de valor |
| **Quadrant** | Análisis comparativo |
