# Integraciones externas

> Servicios externos que consume Capta.Credivoucher.

---

## ✍️ CeroPapel

**Propósito:** firma digital.

**Tipo:** API REST.

**Uso:** firma de contratos de prospectos.

---

## 🤖 Análisis de Riesgo IA

**Propósito:** scoring crediticio.

**Tipo:** API REST.

**Uso:** análisis de prospectos.

---

## 🏦 STP / SPEI

**Propósito:** transferencias bancarias.

**Tipo:** API REST.

**Uso:** dispersión de vales.

---

## 🔍 Nubarium

**Propósito:** validación de CURP.

**Tipo:** API REST.

---

## 📈 Quash

**Propósito:** scoring adicional.

**Tipo:** API REST.

---

## 📧 SMTP

**Propósito:** envío de correos.

**Tipo:** SMTP.

**Uso:** notificaciones.

---

## 📱 SMS

**Propósito:** envío de mensajes.

**Tipo:** API REST.

**Uso:** notificaciones.

---

## 🏪 OXXO

**Propósito:** puntos de pago.

**Tipo:** API REST.

**Uso:** recepción de pagos.

---

## 🕸️ Make (Webhooks)

**Propósito:** automatización.

**Tipo:** Webhook.

---

## 🔒 Reglas

1. **Timeout configurado.**
2. **Reintentos automáticos.**
3. **Circuit breaker si falla seguido.**
4. **Logging de todas las llamadas.**
5. **Credenciales en config, no en código.**
