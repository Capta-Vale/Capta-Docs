## ✅ Al final del onboarding

El nuevo desarrollador debe:

- [ ] Conocer la arquitectura
- [ ] Conocer los estándares
- [ ] Hacer commits correctamente
- [ ] Seguir el flujo de PR
- [ ] Identificar reglas de negocio
- [ ] Poder hacer cambios sin supervisión constante
