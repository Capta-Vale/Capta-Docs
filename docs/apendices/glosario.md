# Glosario

> Términos del negocio y técnicos usados en Capta.Credivoucher.

---

## 💼 Términos de negocio

| Término | Significado |
|---|---|
| **Enlace** | Distribuidor de vales |
| **Cliente** | Persona que recibe un vale |
| **Vale** | Documento prepago entregado al cliente |
| **Pagaré** | Documento de deuda derivado de un vale canjeado |
| **Canje** | Proceso de convertir un vale en pagaré + transferencia |
| **Abono** | Pago parcial de un pagaré |
| **Corte** | Cierre quincenal de cobranza |
| **Convenio** | Reestructuración de deuda |
| **Condonación** | Cancelación parcial o total de deuda |
| **Tape** | Archivo mensual con el detalle de la cartera |
| **Prospecto** | Candidato a convertirse en enlace |
| **Pre-registro** | Prospecto capturado pero no validado |
| **Buró** | Buró de Crédito |
| **CeroPapel** | Servicio de firma digital |
| **Cartera** | Conjunto de créditos activos |
| **Quebranto** | Crédito que no se recuperará |
| **Mora** | Interés por atraso |
| **Dispersión** | Entrega del vale al cliente |
| **Sucursal** | Punto de atención |
| **Coordinador** | Supervisor de sucursal |
| **Mesa de Control** | Área que autoriza operaciones especiales |
| **Afiliación** | Área que da de alta nuevos enlaces |

---

## 💻 Términos técnicos

| Término | Significado |
|---|---|
| **Info** | DTO de datos entre capas |
| **Filter** | DTO de parámetros de búsqueda |
| **Entity** | Representación de tabla en BD |
| **DAO** | Data Access Object |
| **DomainObject** | Objeto de dominio (orquesta DAOs) |
| **Manager** | Fachada de negocio |
| **Controller** | Controller MVC |
| **ViewModel** | Modelo de vista |
| **Binding** | Vinculación de datos en Knockout |
| **Azman** | Sistema de permisos |
| **SP** | Stored Procedure |
| **ETL** | Extract, Transform, Load |
| **ADRs** | Architecture Decision Records |
| **Tech debt** | Deuda técnica |
