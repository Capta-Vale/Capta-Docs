|---|---|

---

## 🎯 Cómo usar

1. Copiar el contenido de `agente-ia-capta.md`.
2. Pegarlo como **system prompt** en tu agente (Claude, ChatGPT, Copilot, etc.).
3. Adjuntar los archivos del proyecto según lo indique el prompt.
4. Trabajar normalmente.
